# Features

## Core
- Multi-week courses with flexible weekly schedules
- Two daily check-ins (AM/PM)
- QR + PIN attendance capture

## Roles
- Admin: full control
- Coordinator: manage courses/cohorts/schedules
- Verifier: run sessions and validate attendance
- Instructor: read-only summaries
- Attendee: self check-in + history

## Attendance Controls
- Grace period + late status
- Manual overrides with reason
- Second-chance tokens per attendee/slot

## Operations
- Session cancellation and reschedule
- Bulk close: mark missing as absent
- Attendance reasons (excused categories)
- Notes per attendee/session

## Data Integrity
- Unique check-in per slot and attendee
- Slot locking and role-based unlock approvals
- Full audit log of manual changes

## Reporting
- Per-session attendance sheet
- Per-attendee history
- Export CSV/Excel

## Administration
- Enrollment import with validation feedback
- Organization settings (time zone, defaults)
- QR expiry and grace period defaults

## Localization
- Full bilingual UI (French/English)
