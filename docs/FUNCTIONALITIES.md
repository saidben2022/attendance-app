# Functionalities

## Scheduling
- Create cohorts with date range
- Define days of week and AM/PM windows
- Add exceptions (holidays or extra sessions)
- Generate sessions automatically
- Cancel or reschedule individual sessions

## Attendance Capture
- Verifier opens AM/PM slot
- Attendee scans QR and confirms phone + member id + PIN
- System records timestamp and status
- Slot can be closed and locked
- Prevent duplicate check-ins per slot

## Verification and Overrides
- Verifier marks late/absent/excused
- Second-chance token grants one-time check-in
- All overrides require reason and are logged
- Role-based unlock approvals for locked slots
- Notes and excused reason categories

## Accounts
- Attendees log in with phone + password
- Attendees still use PIN for check-in confirmation
- Admin can reset passwords and PINs

## Reporting
- View summary by cohort, session, and attendee
- Export attendance data to CSV/Excel

## Settings
- Organization time zone and defaults
- Grace period and QR expiry configuration
- Attendance status labels and colors

## Data Integrity
- Full audit trail for manual actions
- Unique constraints on attendee + slot
