# Design

## UX Goals
- Fast daily flow for verifiers
- Minimal steps for attendees
- Clear status indicators (present/late/absent)
- Usable on low bandwidth connections

## Layout
- Mobile-first for attendee check-in
- Desktop-first for admin/coordinator dashboards
- Separate verifier dashboard optimized for daily operations
- Full-screen QR display for in-room projection

## Visual Style
- Clean, professional, education-focused
- High contrast status colors (green/yellow/red)
- Simple typography with strong hierarchy

## Accessibility
- Large tap targets on mobile
- Clear error messaging and validation
- Bilingual labels for all user actions
